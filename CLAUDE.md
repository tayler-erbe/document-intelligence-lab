# Rules for this repository

This is the PUBLIC catalogue for Tayler Erbe's Document Intelligence Lab.

- Publish public-benchmark results, aggregates or design only. Never add private documents, document text, extracted values, model outputs from private runs, internal hostnames or file paths, credentials, or the names of colleagues or managers.
- Every number on a page must match its source study (repository README, report or data). Do not round in a way that changes meaning, and state comparisons precisely (for example, same-model against production-baseline speedups).
- Do not describe AI-reviewer scores as measured accuracy, prototypes as production-approved, or benchmark results as real-document accuracy.
- `styles.css` and `site.css` are shared Lab stylesheets; keep them identical to the other Lab briefs. Catalogue styles go in `lab.css`; brief styles in `shared/study.css`.
- Write for a general audience: plain language first, technical detail second.
